# Варіант 06 — Бібліотечне обслуговування

Для лабораторної роботи №1 проєктуйте тест-кейси за цією специфікацією, без перегляду вихідного коду. Визначайте очікувані результати за наведеними вимогами. Аналіз коду починається з лабораторної роботи №2.

Наразі доступна лише специфікація. Реалізацію SUT та інструкцію запуску для ручного виконання тест-кейсів буде додано пізніше.

## Опис системи

Система оформлює видачу однієї книги або продовжує чинну позику з урахуванням категорії книги та обмежень читача.

## Вхідні дані

- Запитаний строк: від 1 до 30 днів.
- Поточна кількість позик читача: від 0 до 10; для продовження — не менше 1.
- Ознаки довідкового видання та продовження чинної позики: так або ні.
- Умови обслуговування: кількість доступних примірників і наявність іншого читача в черзі на книгу.

## Бізнес-правила

1. Нова видача заборонена, якщо читач уже має 5 або більше позик. Продовження не збільшує їх кількість і не обмежується цим порогом.
2. Довідкове видання дозволено брати щонайбільше на 7 днів; його продовження заборонене за будь-якого строку.
3. Обмеження кількості позик перевіряється перед обмеженням довідкового видання.
4. Для нової видачі потрібен хоча б один доступний примірник. Черга інших читачів для цієї операції не враховується.
5. Для продовження доступний примірник не потрібен, але наявність іншого читача в черзі забороняє продовження.
6. Перші 14 днів користування безкоштовні; кожен запитаний день понад 14 коштує 100 копійок. Для продовження враховується лише новий запитаний строк.
7. Успішна видача збільшує кількість позик на одну; успішне продовження залишає її незмінною.
8. Успішна операція фіксується один раз. Відмова не змінює кількість позик і чинний строк.

## Правила валідації

Усі числові вхідні значення мають бути цілими; зазначені межі включні. Обов’язкові значення не можна пропускати. Логічні ознаки мають лише значення «так» або «ні». Значення поза допустимими діапазонами відхиляються до застосування бізнес-правил і не змінюють стан системи.

## Очікувана поведінка

Результат: «Видано» або «Продовжено» зі строком, платою та новою кількістю позик. Причини відмови: «Ліміт позик», «Обмеження довідкового видання», «Немає примірника» або «Є черга».

## Помилкові ситуації

Некоректні вхідні дані спричиняють помилку валідації. Від’ємна кількість доступних примірників, недоступність потрібних відомостей або неможливість зафіксувати операцію є помилкою обслуговування. Після помилки подальші дії за заявкою не виконуються. Звичайна бізнес-відмова є окремим результатом, а не помилкою валідації.

## Обмеження

Для продовження вважається, що обрана книга вже позичена цьому читачеві. Повернення, прострочення та календарні дати не розглядаються. Грошові суми виражені цілими копійками. За однакових вхідних даних та умов результат має бути однаковим.
