# SUT C — Магазин, варіант 15

Готовий UI для сусіднього SUT B. HTML, CSS та JavaScript; бізнес-правила виконує backend.

## Запуск

Підготуйте залежності, PostgreSQL, міграції та параметри БД за README SUT B.
Із папки sut-b запустіть:

```sh
mvn spring-boot:run
```

Відкрийте http://127.0.0.1:8080/index.html. Якщо змінено порт API, змініть його й в адресі.
Окремого сервера frontend та додаткових аргументів не потрібно. Збережіть сусідні папки sut-b та sut-c-ui.
Для Java запуск кнопкою в IDE також підходить; робоча папка запуску — sut-b.

## Персональне правило

12% від 1400 грн лише на неакційний товар.

## Можливості

Створення та пошук товару, оформлення й перегляд замовлення, повернення та показ повідомлень про відмови.
Форма дозволяє задати умови персонального правила; збережена сума й статус показуються з відповіді API.
Ціна вводиться у гривнях, у запиті передаються копійки.
Посилання з параметром order повторно завантажує замовлення після оновлення сторінки.
Повторне повернення доступне для перевірки повідомлення про заборонену дію.

Для автоматизації використовуйте підписи полів, назви кнопок та data-testid.
Сума має data-kopecks, статус — data-status; повідомлення мають role=status і role=alert.
Кожен сценарій готує власні дані з унікальними кодами. Готових UI-тестів немає.
