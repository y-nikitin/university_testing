# SUT C — Курси, варіант 11

## Запуск

Підготуйте залежності, БД, міграції та конфігурацію за README SUT B.
Із папки sut-b виконайте:

```sh
npm start
```

Відкрийте http://127.0.0.1:8080/index.html або відповідний порт вашого API.
Окремий frontend-сервер не потрібний. Папки sut-b і sut-c-ui мають залишатися сусідніми.
Для запуску Java або C# кнопкою в IDE робоча папка — sut-b.

## Персональне правило

Від 7 днів до початку включно повертається 100% prepaid; за 2–6 днів — 50%; за 0–1 день — 0%. Дні — ціле число 0–36500; 0 означає день початку. Дні передаються аргументом, поточний час не використовується. Скасування після початку не моделюється.

## Можливості

Створення та пошук слухачів і курсів, зарахування, перегляд заявки, завершення навчання та скасування.
Ідентифікатори створених або знайдених ресурсів підставляються у заявку.
UI показує збережені суму, передоплату, повернення коштів і статус. Бізнес-правила виконує backend.
Ціна вводиться у гривнях, API отримує копійки. Дні до початку для скасування задаються вручну.
Кнопки дій залишаються доступними для перевірки заборонених переходів.
Параметр enrollment в адресі дозволяє відкрити збережену заявку після оновлення сторінки.

Для автоматизації доступні підписи полів, назви кнопок, data-testid, role=status та role=alert.
Суми мають data-kopecks, статус — data-status. Кожен сценарій готує власні дані.
Готових UI-тестів немає.
