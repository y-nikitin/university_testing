# SUT C — Доставка, варіант 11

## Запуск

Підготуйте залежності, БД, міграції та конфігурацію за README SUT B.
Із папки sut-b виконайте:

```sh
python -m uvicorn delivery.api:app --host 127.0.0.1 --port 8080
```

Відкрийте http://127.0.0.1:8080/index.html або відповідний порт вашого API.
Окремий frontend-сервер не потрібний. Папки sut-b і sut-c-ui мають залишатися сусідніми.
Для запуску Java або C# кнопкою в IDE робоча папка — sut-b.

## Персональне правило

Термінова доставка дозволена лише при вазі до 10 000 г і відстані до 500 км одночасно. Звичайна доставка допускає всі загальні межі. Персональна відмова відбувається до виклику ShippingPolicy і без запису відправлення. Доплати за терміновість немає.

## Можливості

Створення й пошук клієнта та посилки, реєстрація й перегляд відправлення, відправлення, доставка та скасування.
Ідентифікатори створених або знайдених ресурсів підставляються у заявку.
UI показує збережені тариф, коригування, суму, статус та доступне в моделі повернення коштів.
Бізнес-правила обчислює backend. Грошові поля вводяться у гривнях, API отримує копійки.
Дії залишаються доступними для перевірки заборонених переходів і повідомлень про помилки.
Параметр shipment в адресі дозволяє повторно завантажити запис після оновлення сторінки.

Підписи полів, назви кнопок, data-testid, role=status та role=alert доступні для автоматизації.
Суми мають data-kopecks, статус — data-status. Кожен сценарій готує власні дані.
Готових UI-тестів немає.
