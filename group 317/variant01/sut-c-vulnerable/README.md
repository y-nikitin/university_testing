# SUT C — Навчальна вразлива версія, варіант 01

Запускається разом із сусіднім sut-b-vulnerable. Адреса: http://127.0.0.1:8082/index.html.
Підготовка БД та запуск описані в його README. Використовуйте тільки локально й із вигаданими даними.

Збережено форми номера, бронювання та скасування, персональні суми й статус.
Додано пошук за кодом, редагування коду та привітання через параметр welcome в URL.
Привітання має бути звичайним текстом, а внутрішні контакти та примітки гостей не повинні бути публічними.
