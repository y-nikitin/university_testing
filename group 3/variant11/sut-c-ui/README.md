# SUT C — Прокат обладнання, варіант 11

HTML, CSS та JavaScript для сусіднього SUT B.

## Запуск

Підготуйте залежності, БД, міграції та параметри підключення за README SUT B.
Із папки sut-b виконайте:

```sh
dotnet run
```

Відкрийте http://127.0.0.1:8080/index.html (або відповідний порт вашого API).
Окремий frontend-сервер не потрібний. Збережіть сусідні папки sut-b і sut-c-ui.
При запуску Java, Go або C# з IDE робоча папка — sut-b.

## Персональне правило

Прострочення задається цілим числом днів 0–36500. При 0 або 1 дні доплата нульова. За кожен день після першого доплата становить 10% добової вартості всіх орендованих одиниць. Спочатку рахується загальна доплата, потім вона округлюється донизу до цілої копійки. Максимум — початкова сума оренди.

## Можливості

Створення та пошук обладнання, оформлення й перегляд оренди, повернення та повідомлення про відмови.
Добова ціна вводиться у гривнях, API отримує копійки.
Усі суми, статус і персональні результати надходять із backend.
Посилання з параметром rental відновлює перегляд після перезавантаження сторінки.
Кнопка повернення дозволяє перевірити повторну заборонену дію.

Для автоматизації доступні підписи полів, назви кнопок, data-testid, role=status та role=alert.
Суми мають data-kopecks, статус — data-status. Використовуйте власні дані для кожного сценарію.
Готових UI-тестів немає.
